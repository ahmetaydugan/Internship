# Artificial Intelligence and System Log Analysis Internship Log:
This repository is created to regularly track and report the artificial intelligence fundamentals I acquired, practical coding tasks, and daily operational processes throughout my 9-week Turkcell internship program.

As the final output of this 9-week program, you can access the end-to-end log analysis and anomaly detection dashboard deployed on Streamlit here: 
👉 **[Live Dashboard: internship-anomali.streamlit.app](https://internship-anomali.streamlit.app)**

## Daily Work Rhythm

The standard work schedule followed every day during the internship was as follows:

*   **Academic Block:** Readings and video tutorials planned to establish the foundations of artificial intelligence (from Perceptrons to LLMs and RAG architectures).
*   **Practical Coding Task:** Translating the theoretical knowledge learned in the academic block into code and implementing algorithms.
*   **Daily Team Operations:** Daily operational tasks and team support duties communicated via email.
*   **Friday Presentations:** A 15-minute brief presentation every Friday to share the week's learnings, experiments, and completed projects.

## Repository Structure

To make tracking easier, the repository is structured on a weekly basis. Each week's folder contains the daily theoretical notes, practical codes, and the final presentation for that specific week.

*   `week_01/` to `week_09/`
    *   `codes/`: Contains all the Python scripts (`.py`), output screenshots (`.JPG`), and data files developed during the week's practical tasks.
    *   `day_1.md` to `day_4.md`: Daily logs, article notes, and theoretical concepts learned from Monday to Thursday.
    *   `day_5_Presentation.pdf`: The 15-minute summary presentation file delivered on Friday.
